# Inventory insights for a property management firm

**Situation.** Oakrow Properties had cash tied up in stock that never sold.

**Task.** Oakrow Properties needed this fixed within 3 weeks.

**Action.** Analysed sell-through by product and location with SQL to find dead stock; built a reorder view showing what to restock and what to clear; shared a monthly summary with the buying team.

**Result.** Freed about 12 thousand in tied-up stock.

**Stack:** sql, data visualization, tableau, data analysis
