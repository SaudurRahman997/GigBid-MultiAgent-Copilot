# Analytics dashboard for a nonprofit

_Open Harvest · nonprofit · 2026-07 · 13 weeks_

Open Harvest's customers exported CSVs to see their own usage numbers. I built a component-based single-page front end with charts customers can filter and share. Along the way I designed the Postgres schema and a typed Node.js API serving 1200 accounts, and finally added role-based access and audit logging.

The result: we cut support requests for reports by 14%.
