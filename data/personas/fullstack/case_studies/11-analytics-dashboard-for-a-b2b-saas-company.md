# Analytics dashboard for a B2B SaaS company

_Tallyhq · B2B SaaS company · 2025-08 · 14 weeks_

Tallyhq's customers exported CSVs to see their own usage numbers. I built a component-based single-page front end with charts customers can filter and share. Along the way I designed the Postgres schema and a typed Node.js API serving 120 accounts, and finally added role-based access and audit logging.

The result: we cut support requests for reports by 12%.

**Stack:** react, typescript, node.js, postgresql, tailwind css
