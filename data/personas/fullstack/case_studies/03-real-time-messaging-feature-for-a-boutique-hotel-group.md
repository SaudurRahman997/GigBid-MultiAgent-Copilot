# Real-time messaging feature for a boutique hotel group

**Client:** Saltmarsh Hotels (boutique hotel group)  
**When:** 2022-07, 10 weeks

## Challenge
Users of Saltmarsh Hotels could not message each other inside the product.

## What I did
- Added in-app messaging with live updates, typing indicators and read receipts
- Used a managed realtime database with security rules per conversation
- Built the UI as reusable React components

## Outcome
28% of active users sent a message in week one.

**Stack:** react, firebase, javascript, node.js
