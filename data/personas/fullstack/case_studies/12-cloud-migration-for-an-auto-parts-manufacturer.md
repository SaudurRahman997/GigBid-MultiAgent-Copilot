# Cloud migration for an auto-parts manufacturer

**Client:** Castwell (auto-parts manufacturer)  
**When:** 2025-10, 12 weeks

## Challenge
Castwell's app ran on one ageing server and went down during traffic spikes.

## What I did
- Moved the app from a single server to containers on managed cloud with autoscaling
- Set up CI so every merge is tested and deployed automatically
- Moved the database to a managed Postgres instance with backups

## Outcome
Reduced hosting cost by 35%.
