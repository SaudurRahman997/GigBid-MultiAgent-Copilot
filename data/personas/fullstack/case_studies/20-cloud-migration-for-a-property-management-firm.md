# Cloud migration for a property management firm

**Client:** Urbanest (property management firm)  
**When:** 2026-05, 20 weeks

## Challenge
Urbanest's app ran on one ageing server and went down during traffic spikes.

## What I did
- Moved the app from a single server to containers on managed cloud with autoscaling
- Set up CI so every merge is tested and deployed automatically
- Moved the database to a managed Postgres instance with backups

## Outcome
Reduced hosting cost by 60%.
