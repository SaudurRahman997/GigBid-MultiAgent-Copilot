# Custom storefront for a clinic network

_Brightwater Clinics · clinic network · 2022-06 · 11 weeks_

Brightwater Clinics's theme was slow on mobile and checkout was confusing. I rebuilt the storefront theme with faster product pages and a simpler checkout flow. Along the way I connected inventory and shipping providers through their APIs, and finally set up analytics events for every checkout step.

The result: we cut page load time from 15 to 3 seconds.

**Stack:** shopify, javascript, css, api integration
